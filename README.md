# COVID-19 Data Analysis and Visualisation

HCLTech Career Shaper Programme, IV Year Industry Project, Project 48

Learner: Saloni Singh | Educator: Dipali Kedar

EDA and visualisation of COVID-19 cases, deaths and vaccination for 10 countries (500 daily records, 2024-01-01 to 2024-02-19), with an Excel dashboard.

## Data note
The supplied dataset fails basic consistency checks (for example recovered greater than confirmed in 228 rows) and appears to be synthetic. Impossible values are flagged, not deleted, and findings describe this file only.

## Folders
- data: raw dataset, cleaned dataset, data dictionary
- notebooks: EDA notebook (Python)
- figures: charts used in the report
- dashboard: Excel dashboard (PivotTables, PivotCharts, slicer)
- reports: synopsis 

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Jupyter, Excel
